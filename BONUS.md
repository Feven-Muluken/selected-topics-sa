# Bonus work

This repository completes bonus option **(d): parameter-sensitivity study with
heat maps**.

The tuning experiment evaluates acceptance targets, initial-temperature
settings, final temperatures, and moves per temperature block using five
independent runs per configuration under the same 50,000-evaluation budget.
`experiments/make_tuning_heatmaps.py` aggregates those results and writes two
heat maps per benchmark instance:

- acceptance target versus initial temperature;
- final temperature versus moves per temperature block.

The generated images are saved under `results/plots/tuning/`. Reproduce them
with:

```bash
python3 -m experiments.make_tuning_heatmaps
```

The source tuning data is `results/tuning/grid.csv`, generated by:

```bash
python3 -m experiments.tune_parameters
```

Lower mean final cost indicates a better configuration. The heat maps are
intended to show sensitivity patterns rather than replace the final
30-independent-run evaluation.
